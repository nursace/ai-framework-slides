# Самостоятельная работа

## Тема

Полный цикл решения задачи машинного обучения на реальном наборе данных.

## Цель работы

Научиться самостоятельно находить и подготавливать данные, проводить исследовательский анализ, обучать несколько моделей машинного обучения, оценивать качество результатов и визуально представлять выводы.

## Задание

Выберите открытый набор данных для задачи классификации или регрессии. Данные можно найти на Kaggle, UCI Machine Learning Repository, OpenML или других открытых источниках.

Выполните следующие этапы.

### 1. Поиск и описание данных

- Найдите набор данных, содержащий достаточное количество объектов и признаков.
- Укажите источник данных и ссылку на него.
- Сформулируйте задачу: классификация или регрессия.
- Опишите целевую переменную и основные признаки.
- Укажите размер набора данных: количество строк и столбцов.

### 2. Первичный анализ и подготовка данных

Проведите EDA (Exploratory Data Analysis):

- выведите первые строки таблицы;
- изучите типы данных;
- проверьте наличие пропущенных значений;
- найдите дубликаты;
- изучите основные статистические показатели числовых признаков;
- проанализируйте категориальные признаки;
- выявите выбросы и аномальные значения;
- изучите распределение целевой переменной;
- исследуйте связь признаков с целевой переменной.

Подготовьте данные для обучения модели:

- обработайте или удалите пропущенные значения;
- удалите дубликаты, если они есть;
- преобразуйте категориальные признаки в числовой формат;
- при необходимости нормализуйте или стандартизируйте числовые признаки;
- разделите данные на обучающую и тестовую выборки;
- при необходимости выполните отбор или создание новых признаков.

Все решения по очистке и преобразованию данных должны быть кратко объяснены.

### 3. Обучение моделей

Обучите не менее трёх моделей машинного обучения. Рекомендуемые алгоритмы:

- Linear Regression — для задачи регрессии;
- Logistic Regression — для задачи классификации;
- K-Nearest Neighbors (KNN);
- Decision Tree;
- Random Forest;
- Support Vector Machine;
- Naive Bayes.

Подберите основные параметры моделей. Сравните результаты моделей и выберите лучшую.

### 4. Оценка качества моделей

Для задачи классификации рассчитайте:

- Accuracy;
- Precision;
- Recall;
- F1-score;
- ROC-AUC, если применимо;
- confusion matrix.

Для задачи регрессии рассчитайте:

- MAE;
- MSE;
- RMSE;
- R²-score.

Сделайте вывод о том, какая модель показала лучший результат и почему.

### 5. Визуализация результатов

Добавьте подходящие графики. Рекомендуемые варианты:

- гистограммы распределения числовых признаков;
- boxplot для поиска выбросов;
- countplot для категориальных признаков;
- heatmap корреляций;
- scatter plot для исследования взаимосвязей;
- графики распределения целевой переменной;
- confusion matrix в виде heatmap;
- ROC-кривая и Precision–Recall curve;
- график важности признаков для моделей, где это возможно;
- сравнение метрик моделей в виде столбчатой диаграммы;
- для регрессии — график «фактические значения vs предсказанные значения».

Каждый график должен иметь заголовок, подписи осей и краткое пояснение.

## Требования к результату

Работа должна быть оформлена в виде Jupyter Notebook (`.ipynb`) или Google Colab Notebook. Ноутбук должен быть логично структурирован, содержать комментарии к коду, выводы после каждого важного этапа и итоговое заключение.

## Итоговое заключение

В конце работы ответьте на вопросы:

1. Какой набор данных был выбран и какую задачу он решает?
2. Какие проблемы были обнаружены в данных?
3. Какие методы подготовки данных были использованы?
4. Какие модели были обучены?
5. Какая модель оказалась лучшей по метрикам?
6. Какие признаки наиболее важны для результата?
7. Что можно улучшить в дальнейшем?
